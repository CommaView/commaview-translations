## 실시간 사본과 다시 보기

| | 실시간 사본 | 다시 보기 |
| --- | --- | --- |
| 보여 주는 것 | Live View에 보였던 화면 그대로 | comma 자체 영상 위에 주행 화면을 그린 것 |
| 준비되는 때 | 멈추는 즉시 | 주차하고 **다시 보기 만들기**를 누른 뒤 |
| 길이 | 저장 공간 외에는 제한 없음 | 녹화당 최대 10분 |
| 화질 | 720p 또는 1080p, 초당 20프레임 | 최고 화질: **Balanced**, **High**, **Max** |

## 라이브 방송 중에는

실시간 사본과 [라이브 방송](/ko/guides/go-live)은 인코더 하나를 함께 씁니다. 방송 중에 시작한 사본은 방송 화질을 따릅니다. 설정 › 녹화의 **각 라이브 방송 저장**을 켜면, 녹화하지 않아도 라이브 방송마다 보낸 그대로의 MP4를 남깁니다.

## 개인정보 보호

실시간 사본은 휴대폰에 남습니다. 업로드되지 않으며, comma와 페어링된 다른 휴대폰과 공유되지도 않습니다. **CommaView로 보내기**는 주행의 comma 자체 데이터를 보내며, 실시간 사본은 절대 보내지 않습니다. 소리는 마이크를 골랐을 때만, 운전자 카메라는 운전자 카메라가 켜져 있는 동안에만 사본에 들어갑니다.

## 안전

설정 선택과 녹화 시작은 주차 상태에서 하세요. 운전 중에는 CommaView를 조작하지 마세요. openpilot이 요구하는 대로 눈은 도로에, 손은 핸들에 두세요.
