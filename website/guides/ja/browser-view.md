## 車内にインターネットがない場合

短いリンクのページを開くには、テザリングのモバイルデータか車自身の接続で、車がオンラインである必要があります。オンラインでない場合は、スマートフォンのアドレスを直接開きます。カードで **車内にインターネットがない場合は？ アドレスを表示** をタップします。

- **最高画質**：`https://192.168.43.1:8443/48291374` のような HTTPS アドレス。このアドレスはスマートフォン自身が署名しているため、ブラウザが先に警告を表示します。警告を承諾して進んでください。Tesla のブラウザでは先に進めません。
- **標準画質**：`192.168.43.1:8090/48291374` のような、同じアドレスの HTTP 版。Tesla を含むどのブラウザでも警告は出ませんが、画質は低く、なめらかさも劣ります。

VPN アドレスがオンのときは、代わりにそのアドレス `https://169.254.99.1:8443/<code>` と `169.254.99.1:8090/<code>` が表示されます。インターネットのない Tesla では標準画質の方を使ってください。

スマートフォンのテザリングのアドレスは例と異なる場合があります。カードには常に正しいアドレスが、それぞれの横にコピーボタン付きで表示されます。

## カードの選択肢

- **Browser View の画質：720p または 1080p。** 1080p の方が鮮明ですが、スマートフォンとテザリングの負荷が大きくなります。選ぶまでは 720p です。
- **Live View と一緒に開始。** Live View を開くたびに Browser View が始まります。VPN アドレスがオンならそれも使います。停止すると、次に Live View を開くまで停止したままです。
- **新しいコード。** 新しい 8 桁のコードを作成し、ほかの人に見られたアドレスを使えなくします。車で新しいアドレスを開いてください。
- **車内での操作。** 録画、場面を保存などの Live View の操作ボタンは、映像の下か運転席側の横に並び、映像に重なることはありません。カードの **車内での操作** でオフにできます。
- **ドライバーカメラ** も、Live View の **ドライバーカメラ** がオンの間は車に表示されます。

## 実行中

- **Browser View はスマートフォンをロックしても続きます。** ほかのアプリに切り替えても同様です。通知に「Browser View で Live View を表示中」と表示され、その **停止** で終了します。
- **Live View を離れると終了します。** ライブ配信やライブコピーと同じです。
- **Browser View と並行してライブ配信** すると、同じ映像を共有します。Browser View だけが動いているときに配信を始めると、音声は入りません。音声が必要なら先に Browser View を停止してください。

## プライバシーとセキュリティ

- 映像は、スマートフォンのテザリングか Wi‑Fi 上の、コードを持つブラウザにだけ届きます。モバイルデータ経由や CommaView のサーバー経由では決して送りません。
- 1 台のデバイスから 1 分間に 10 回コードを間違えると、そのデバイスは 1 分間締め出されます。すでに視聴中のデバイスはそのまま続きます。
- Browser View の実行中、スマートフォンは短いリンクがスマートフォンを見つけられるよう、CommaView のアカウントサービスに、コード、ポート、VPN アドレスがオンかどうか、テザリングまたは Wi‑Fi のプライベートアドレスを送ります。Browser View の実行中と、予期せず止まってから最大 2 時間は、コードを持つ人ならこれらとスマートフォンの `commaview.app` の名前を見られます。ただし、スマートフォンのテザリングか Wi‑Fi がなければ、どれも何も開けません。これらは Browser View を最後に使ってから 30 日後に削除されます。スマートフォンの `commaview.app` の名前と最後の証明書の日付は、アカウントがある間は残ります。証明書は公開されるため、その名前は Certificate Transparency のログに残りますが、あなた、車、comma については何も示しません。詳しくは[プライバシーポリシー](/privacy)をご覧ください。
- VPN アドレスを使うかどうかはあなたが選びます。自動でオンになることはなく、通信も一切通しません。

## よくある質問

**AI ボックスや新しいカーナビが必要ですか？** いいえ。Browser View は車にすでにあるブラウザを使います。車に CarPlay や Android Auto がある場合は、[Android AI ボックス](/ja/blog/android-ai-box-commaview)を使えば車の画面そのもので CommaView を動かせます。

**モバイルデータを使いますか？** 映像は使いません。スマートフォンからテザリング経由で車に届きます。短いリンクのページと、車自身によるテザリングの利用はモバイルデータを使います。

**スマートフォンの代わりに comma のテザリングでもできますか？** ほとんどのブラウザでは可能です。スマートフォンと車を comma のテザリングにつなぎ、カードに表示されるアドレスを開いてください。Tesla には VPN アドレスが必要で、これはスマートフォン自身のテザリングにつながった車でしか使えません。

## 安全のために

Browser View の設定は停車中に行い、その後は触らないでください。運転中に CommaView を操作しないでください。openpilot が求めるとおり、目は道路に、手はハンドルに。comma 自身のアラートと車の計器が最優先です。CommaView は comma が見ているものを表示するだけです。
