## サポートバンドルに入るもの

- **このスマートフォンの診断データ。** このスマートフォンの CommaView の診断ログとカウンター：映像の配信、描画、接続、録画のエラーと、アプリのバージョン、スマートフォンの機種と Android のバージョン。ナビを使っている場合は、種類ごとに場所の検索が何回成功・失敗したかも入ります。何を検索したかは入りません。
- **comma のログ。** comma の行がオンの場合：CommaView ランタイムのログ、カウンター、設定、どの openpilot のプロセスがなぜ止まったか、comma のカーネルのメモリー不足の行。
- **バンドルに決して入らないもの。** 映像、GPS の位置情報、VIN、生の走行テレメトリーは入りません。送った録画はバンドルの横に付くもので、バンドルの中には入りません。最新の comma ランタイムは、ログを送る前に GPS 座標、VIN、Wi‑Fi 名、パブリック IP アドレス、トークン、完全なドングル ID を取り除きます。
- **送ったときだけ。** バンドルがスマートフォンから出るのは、「送信」か「ファイルとして保存」をタップしたときだけです。保存したファイルは、送った先にだけ届きます。ローカル IP アドレス、セッション ID、バージョンの詳細は残ることがあるので、バンドルは信頼できる人とだけ共有してください。

## 送り先と保存期間

送ったバンドルは CommaView の非公開のストレージに届き、開けるのは CommaView チームだけです。送ってから 180 日後に削除されます。削除を依頼した場合やアカウントを削除した場合は、その時点ですぐに削除されます（[プライバシー](/privacy)）。依頼は support@commaview.com までメールしてください。

アプリがこのスマートフォンに残しているものを消すには、**サポートと診断** の **ローカルの診断データを消去** をタップします。録画が削除されることはありません。以後は録画のエラーの履歴だけを残すには、同じページの **診断データをこのスマートフォンに保存** をオフにします。

どこに送ればよいかわからない場合は、[CommaView Discord](https://discord.gg/UuMhz9K8ft) で質問してください。
