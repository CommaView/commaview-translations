## セットアップの段階

各段階はその前の段階を必要とするので、この順に確認してください。

1. **SSH**（ポート 22）：セットアップがインストールのために comma に入る方法です。GitHub の鍵、comma に入力した GitHub ユーザー名、オンになった SSH が必要です。
2. **インストール**：comma がランタイムをダウンロードしてインストールします。その後の段階を見る前に、まずこの結果を読んでください。
3. **ランタイム**（comma のポート 5002）：セットアップが応答を確認し、ペアリングします。
4. **ペアリング**：1 回限りのペアリングコードで、スマートフォンに comma 用の専用の鍵を渡します。
5. **映像**（ポート 8200〜8202）：Live View のカメラ。

検出で comma が見つからなくても、アドレスがわかっていれば入力するだけで同じように接続できます。検出は便利な機能にすぎず、大事なのは comma に接続できることです。

## 安全のために

セットアップ、インストール、トラブルシューティングは、openpilot を解除して車を P レンジに入れた状態で行ってください。運転中にセットアップしたり、アプリを操作したりしないでください。
