## ตั้งค่าเองจากเทอร์มินัล

เฉพาะเมื่อ SSH จากคอมพิวเตอร์ไปยัง comma ในชื่อผู้ใช้ `comma` ใช้งานได้อยู่แล้ว

1. ใน CommaView เลือก **ตั้งค่าเอง** แล้ว **ไปที่การตั้งค่าเอง** แอปจะแสดงคำสั่งสำหรับรันไทม์ของแอปที่ **ติดตั้งจากเทอร์มินัลของคุณ** พร้อมให้คัดลอก (**แตะเพื่อคัดลอก**) หน้าตาคล้ายคำสั่งนี้ ซึ่งติดตั้งรันไทม์ของรุ่นปัจจุบัน:

   ```
   curl -fsSL https://commaview.com/commaviewd/install.sh \
     | ssh comma@COMMA_IP bash
   ```

2. รันคำสั่งจากคอมพิวเตอร์ที่อยู่ใน Wi‑Fi เดียวกับ comma โดยแทน `COMMA_IP` ด้วยที่อยู่ IP ของ comma (**การตั้งค่า → เครือข่าย** บน comma: ใต้ชื่อเครือข่ายบนปุ่ม Wi‑Fi ใน comma four หรือใต้ **ขั้นสูง** ใน comma 3X) คอมพิวเตอร์จะดาวน์โหลดตัวติดตั้ง และ SSH จะรันบน comma ในชื่อผู้ใช้ `comma`
3. เมื่อตัวติดตั้งทำงานเสร็จ CommaView จะเริ่มทำงานบน comma และแสดงรหัสจับคู่แบบใช้ครั้งเดียว
4. กลับไปที่ CommaView แตะ **ฉันรันคำสั่งแล้ว** ที่ **เพิ่ม comma ของคุณ** เลือก comma หรือป้อน IP พิมพ์รหัสจับคู่ แล้วแตะ **เพิ่ม comma** แอปจะตรวจรันไทม์และบันทึก comma ไว้

ลองใช้ขณะอยู่ในเกียร์ P ก่อนออกรถ

- หน้าแรกแสดง comma ของคุณว่า **เชื่อมต่อแล้ว**
