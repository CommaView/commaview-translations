## ส่วนต่างๆ ที่การตั้งค่าทำผ่าน

แต่ละส่วนต้องอาศัยส่วนก่อนหน้า จึงควรตรวจตามลำดับนี้:

1. **SSH** พอร์ต 22: วิธีที่การตั้งค่าเข้าสู่ comma เพื่อติดตั้ง ต้องมีคีย์ GitHub ชื่อผู้ใช้ GitHub บน comma และเปิด SSH
2. **การติดตั้ง**: comma ดาวน์โหลดรันไทม์และติดตั้ง อ่านผลลัพธ์ก่อนดูส่วนถัดไป
3. **รันไทม์** พอร์ต 5002 บน comma: การตั้งค่าตรวจว่ารันไทม์ตอบสนอง แล้วจับคู่ด้วย
4. **การจับคู่**: รหัสจับคู่แบบใช้ครั้งเดียวให้โทรศัพท์มีคีย์ของตัวเองสำหรับ comma
5. **วิดีโอ** พอร์ต 8200 ถึง 8202: กล้องของ Live View

ถ้าการค้นหาไม่พบ comma แต่คุณรู้ที่อยู่ การพิมพ์ที่อยู่ก็ใช้ได้เหมือนกัน: การค้นหาเป็นแค่ความสะดวก สิ่งสำคัญคือติดต่อ comma ได้

## ความปลอดภัย

ตั้งค่า ติดตั้ง และแก้ปัญหาขณะรถอยู่ในเกียร์ P และ openpilot ไม่ได้เข้าควบคุม อย่าตั้งค่าหรือกดใช้แอปขณะขับ
