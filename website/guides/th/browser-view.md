## ไม่มีอินเทอร์เน็ตในรถ

ลิงก์สั้นต้องให้รถออนไลน์เพื่อโหลดหน้าเว็บ ผ่านอินเทอร์เน็ตมือถือของฮอตสปอตหรือการเชื่อมต่อของรถเอง ถ้าไม่มี ให้เปิดที่อยู่ของโทรศัพท์โดยตรง บนการ์ด แตะ **ไม่มีอินเทอร์เน็ตในรถ? แสดงที่อยู่**:

- **ภาพดีที่สุด** ที่อยู่ HTTPS เช่น `https://192.168.43.1:8443/48291374` เบราว์เซอร์จะเตือนก่อน เพราะโทรศัพท์รับรองที่อยู่นี้เอง: ยอมรับคำเตือนเพื่อดำเนินการต่อ เบราว์เซอร์ของ Tesla ไม่ยอมให้ผ่าน
- **ภาพพื้นฐาน** ที่อยู่เดียวกันผ่าน HTTP เช่น `192.168.43.1:8090/48291374` ไม่มีคำเตือนในเบราว์เซอร์ใด รวมถึง Tesla แต่ภาพคุณภาพต่ำกว่าและลื่นน้อยกว่า

เมื่อเปิดที่อยู่ VPN การ์ดจะแสดงที่อยู่ของ VPN แทน คือ `https://169.254.99.1:8443/<code>` และ `169.254.99.1:8090/<code>` ใน Tesla ที่ไม่มีอินเทอร์เน็ต ให้ใช้แบบพื้นฐาน

ที่อยู่ฮอตสปอตของโทรศัพท์อาจต่างจากตัวอย่าง การ์ดจะแสดงที่อยู่ที่ถูกต้องเสมอ พร้อมปุ่มคัดลอกข้างแต่ละรายการ

## ตัวเลือกบนการ์ด

- **ภาพ Browser View: 720p หรือ 1080p** 1080p คมชัดกว่า และใช้ทรัพยากรของโทรศัพท์และฮอตสปอตมากกว่า เป็น 720p จนกว่าคุณจะเลือก
- **เริ่มพร้อม Live View** Browser View เริ่มทุกครั้งที่ Live View เปิด พร้อมที่อยู่ VPN ถ้าเปิดไว้ ถ้าหยุดจะหยุดอยู่จนกว่า Live View จะเปิดอีกครั้ง
- **รหัสใหม่** สร้างรหัสแปดหลักใหม่ ที่อยู่ที่คนอื่นเคยเห็นจะใช้ไม่ได้อีก เปิดที่อยู่ใหม่ในรถ
- **ปุ่มควบคุมในรถ** บันทึก เก็บช่วงเวลา และปุ่มควบคุมอื่นของ Live View อยู่ใต้ภาพหรือข้างภาพด้านคนขับ ไม่บังภาพ **ปุ่มควบคุมในรถ** บนการ์ดใช้ปิดปุ่มเหล่านี้
- **กล้องฝั่งคนขับ** แสดงในรถด้วยขณะเปิด **กล้องคนขับ** ของ Live View

## ระหว่างทำงาน

- **Browser View ทำงานต่อเมื่อล็อกโทรศัพท์** หรืออยู่ในแอปอื่น การแจ้งเตือนจะแสดง “กำลังแสดง Live View ใน Browser View” และ **หยุด** ในการแจ้งเตือนจะปิด Browser View
- **การออกจาก Live View จะปิด Browser View** เช่นเดียวกับการถ่ายทอดสดและสำเนาสด
- **ถ่ายทอดสดคู่กับ Browser View** ใช้ภาพร่วมกัน สตรีมที่เริ่มขณะ Browser View ทำงานอยู่อย่างเดียวจะไม่มีเสียง: หยุด Browser View ก่อนถ้าต้องการเสียง

## ความเป็นส่วนตัวและความปลอดภัย

- ภาพไปเฉพาะเบราว์เซอร์ในฮอตสปอตหรือ Wi‑Fi ของโทรศัพท์ที่มีรหัส ไม่เคยผ่านอินเทอร์เน็ตมือถือ และไม่เคยผ่านเซิร์ฟเวอร์ของ CommaView
- ใส่รหัสผิดสิบครั้งในหนึ่งนาทีจากอุปกรณ์เดียว อุปกรณ์นั้นจะถูกล็อกหนึ่งนาที ส่วนอุปกรณ์ที่ดูอยู่แล้วดูต่อได้
- ระหว่างที่ Browser View ทำงาน โทรศัพท์จะส่งรหัส พอร์ต สถานะที่อยู่ VPN และที่อยู่ส่วนตัวของฮอตสปอตหรือ Wi‑Fi ไปยังบริการบัญชีของ CommaView เพื่อให้ลิงก์สั้นหาโทรศัพท์เจอ ผู้ที่มีรหัสจะเห็นข้อมูลเหล่านี้และชื่อ `commaview.app` ของโทรศัพท์ ระหว่างที่ Browser View ทำงาน และนานสูงสุด 2 ชั่วโมงหลังหยุดโดยไม่คาดคิด ข้อมูลเหล่านี้เปิดอะไรไม่ได้หากไม่ได้อยู่ในฮอตสปอตหรือ Wi‑Fi ของโทรศัพท์ ข้อมูลจะถูกลบ 30 วันหลัง Browser View ทำงานครั้งล่าสุด ชื่อ `commaview.app` ของโทรศัพท์และวันที่ของใบรับรองล่าสุดจะอยู่ตราบที่บัญชีของคุณยังอยู่ ใบรับรองเป็นข้อมูลสาธารณะ ชื่อนั้นจึงอยู่ในบันทึก Certificate Transparency แต่ไม่ได้บอกอะไรเกี่ยวกับคุณ รถ หรือ comma ของคุณ [นโยบายความเป็นส่วนตัว](/privacy)มีรายละเอียด
- ที่อยู่ VPN เป็นตัวเลือกของคุณ ไม่เคยเปิดเอง และไม่มีข้อมูลผ่าน

## คำถาม

**ต้องใช้ AI box หรือจอในรถตัวใหม่ไหม?** ไม่ Browser View ใช้เบราว์เซอร์ที่รถมีอยู่แล้ว ถ้ารถมี CarPlay หรือ Android Auto แทน [AI box ที่ใช้ Android](/blog/android-ai-box-commaview) จะรัน CommaView บนหน้าจอรถได้เลย

**ใช้อินเทอร์เน็ตมือถือของฉันไหม?** ภาพไม่ใช้: ส่งจากโทรศัพท์ไปยังรถผ่านฮอตสปอต หน้าเว็บของลิงก์สั้นและการใช้ฮอตสปอตของรถเองจะใช้

**ใช้ฮอตสปอตของ comma แทนของโทรศัพท์ได้ไหม?** สำหรับเบราว์เซอร์ส่วนใหญ่ได้: ให้โทรศัพท์และรถใช้ฮอตสปอตของ comma แล้วเปิดที่อยู่ที่การ์ดแสดง Tesla ต้องใช้ที่อยู่ VPN ซึ่งใช้ได้เฉพาะกับรถที่อยู่บนฮอตสปอตของโทรศัพท์เอง

## ความปลอดภัย

ตั้งค่า Browser View ขณะจอด แล้วปล่อยไว้ อย่าใช้งาน CommaView ขณะขับ: มองถนนและจับพวงมาลัยไว้ ตามที่ openpilot ขอ การแจ้งเตือนของ comma และมาตรวัดของรถมาก่อนเสมอ CommaView แสดงแค่สิ่งที่ comma เห็น
