CommaView 0.0.166 ออกแล้วสำหรับทุกคนในช่วง Beta ด้วยรันไทม์ใหม่ **แต่ละโทรศัพท์จะได้คีย์ของตัวเอง** สำหรับ comma ของคุณ และไม่ต้องจับคู่ใหม่ CommaView รองรับ **อีก 11 ภาษา** แสดง Live View ในเว็บเบราว์เซอร์ของรถด้วย **Browser View** เก็บการขับขี่ไว้ในโทรศัพท์ด้วย **เก็บช่วงเวลานี้**, **ส่งออกทั้งการขับขี่…** และ **ดึงการขับขี่อัตโนมัติ** และเปิด **ร้านแพ็กโอเวอร์เลย์**

มาพร้อมรันไทม์ `v0.0.62-beta` **อัปเดต CommaView ก่อน** แล้วจึงอัปเดตรันไทม์จากแอปเมื่อแอปเสนอ และรีบูต comma เมื่อแอปขอ โทรศัพท์ที่ยังใช้ 0.0.165 จะใช้งานต่อได้ 90 วันหลังจากโทรศัพท์เครื่องแรกของ comma ได้รับคีย์ อย่าตั้งค่า comma ใหม่จากโทรศัพท์ที่ใช้ 0.0.165: การตั้งค่าจากเครื่องนั้นจะคืนรันไทม์เก่ากลับมา และโทรศัพท์ที่มีคีย์จะเข้าถึง comma บนรันไทม์นั้นไม่ได้

## คีย์สำหรับแต่ละโทรศัพท์

ด้วยรันไทม์ใหม่ แต่ละโทรศัพท์จะได้คีย์ของตัวเองสำหรับ comma ของคุณ แทนโทเค็นที่ใช้ร่วมกันซึ่งทุกโทรศัพท์เคยส่ง คีย์ไม่เคยถูกส่งผ่านเครือข่าย และไม่มีใครต้องจับคู่ใหม่: โทรศัพท์ที่ใช้ 0.0.166 จะได้คีย์ในการเชื่อมต่อครั้งถัดไป

- **โทรศัพท์เครื่องใหม่ได้คีย์** โทรศัพท์ทุกเครื่องที่มีคีย์จะได้รับแจ้งเมื่อมีเครื่องอื่นได้คีย์ พร้อมปุ่ม **เป็นของฉัน**, **ลบ** และ **ตรวจสอบโทรศัพท์** ซึ่งเปิดการตั้งค่าอุปกรณ์ › จับคู่โทรศัพท์เครื่องอื่น ที่แสดงโทรศัพท์ทุกเครื่องที่มีคีย์
- **การเพิ่มโทรศัพท์** **แสดงคำเชิญ** บนโทรศัพท์ที่มีคีย์ จะให้รหัสหรือ QR code ที่ใช้ได้ 10 นาที
- **แอปรุ่นเก่า** comma ของคุณรับโทเค็นที่ใช้ร่วมกันแบบเก่าต่อไปอีก 90 วันหลังจากโทรศัพท์เครื่องแรกได้คีย์ หรือจนกว่าจะมีคนแตะ **หยุดตอนนี้** ระหว่างนั้น **รหัสจับคู่สำหรับแอปรุ่นเก่า** ใช้จับคู่โทรศัพท์ที่ใช้ CommaView รุ่นเก่าได้ หลังจากนั้น โทรศัพท์ที่ไม่มีคีย์ต้องใช้ 0.0.166 และคำเชิญ

## CommaView ในภาษาของคุณ

การตั้งค่า › **ภาษา** ตอนนี้มี Deutsch, Español, Français, 日本語, 한국어, Português (Brasil), ไทย, Türkçe, Українська, 简体中文 และ 繁體中文 นอกจากภาษาอังกฤษ **ภาษาของโทรศัพท์** ซึ่งเป็นค่าเริ่มต้น จะใช้ภาษาแรกในรายการภาษาของโทรศัพท์ที่ CommaView มี ถ้าไม่มีจะใช้ภาษาอังกฤษ และแถวนั้นจะบอกว่ากำลังใช้ภาษาใด บน Android 13 ขึ้นไป การตั้งค่าภาษาแยกตามแอปของ Android ก็ใช้ได้ด้วย

ทุกภาษายกเว้นภาษาอังกฤษ **แปลด้วยเครื่อง** และยังไม่มีเจ้าของภาษาตรวจทานเลย จึงอาจเจอคำผิดและประโยคแปลกๆ การ์ดด้านบนของการตั้งค่าบอกเรื่องนี้ และ **ช่วยปรับปรุง** จะเปิดคำแปลของ CommaView ที่ใครก็เสนอคำที่ดีกว่าได้ คุณบอกเราได้ใน [Discord](https://discord.gg/UuMhz9K8ft) หรือจาก **รายงานปัญหาหรือส่งไอเดีย** ก็ได้: ระบุหน้าจอและข้อความที่แสดงอยู่ตอนนี้

- **หน้าจอของ comma ยังคงเป็นภาษาของ comma** ป้ายของฟอร์กและคำเตือนของ comma จะวาดตามที่รถของคุณแสดง และตอนนี้ใช้ฟอนต์ของฟอร์กเองเมื่อ comma ใช้ภาษาจีน ญี่ปุ่น เกาหลี หรือไทย
- **ข้อความภาษาอังกฤษมีผลบังคับ** สำหรับความยินยอมของตารางอันดับ และ **แสดงเป็นภาษาอังกฤษ** จะแสดงข้อความนั้น นโยบายความเป็นส่วนตัวและข้อกำหนดเป็นภาษาอังกฤษ
- **วันที่** เรียงตามแบบของภาษาที่คุณใช้ และชื่อกับคำอธิบาย YouTube ของถ่ายทอดสด เป็นภาษาของแอปจนกว่าคุณจะเปลี่ยน
- **ภาษาเกาหลี** ไม่ตัดคำกลางคำที่ท้ายบรรทัด บน Android 13 และเก่ากว่า ชื่อภาษาเกาหลีที่คุณตั้งให้ comma หรือสถานที่อาจยังถูกตัดได้

## Browser View

Browser View แสดงสิ่งที่ Live View แสดงในเว็บเบราว์เซอร์ของรถ โดยโทรศัพท์ของคุณเป็นผู้ให้บริการผ่านฮอตสปอตหรือ Wi‑Fi เริ่มได้จาก Live View › รายละเอียด › Browser View พิมพ์ลิงก์สั้น `commaview.app/<code>` ในเบราว์เซอร์ของรถ แล้วแตะ **เปิด** ใน Tesla ให้แตะ **เปิดที่อยู่ VPN** ก่อน

ภาพเดินทางจากโทรศัพท์ไปยังรถ ไม่ผ่านอินเทอร์เน็ต มีเพียงหน้าของลิงก์สั้นเท่านั้นที่ผ่าน เมื่อลงชื่อเข้าใช้ โทรศัพท์จะได้ชื่อของตัวเองและใบรับรองที่เชื่อถือได้ Tesla จึงแสดงแม่กุญแจและภาพ H.264 ที่ลื่นกว่า เมื่อไม่ได้ลงชื่อเข้าใช้ Tesla จะได้ภาพพื้นฐาน

- **ปุ่มควบคุมในรถ**: บันทึก เก็บ แผนที่ หน้าจอขณะขับ ถ่ายทอดสด และกล้องคนขับ อยู่ข้างหรือใต้ภาพ ไม่บังภาพ
- **ไม่มีอินเทอร์เน็ตในรถ?** **แสดงที่อยู่** จะแสดงที่อยู่ของโทรศัพท์เอง
- 720p หรือ 1080p รหัสแปดหลัก และ **เริ่มพร้อม Live View** เพื่อเริ่มทุกครั้งที่เปิด Live View

ทุกขั้นตอน รวมถึงของ Tesla: [Browser View](/th/guides/browser-view)

ขณะทำงาน โทรศัพท์จะส่งรหัส พอร์ต และที่อยู่ส่วนตัวไปยังบริการบัญชีของ CommaView เพื่อให้ลิงก์สั้นหาโทรศัพท์เจอ ใครที่มีรหัสจะเห็นข้อมูลเหล่านี้และชื่อ `commaview.app` ของโทรศัพท์คุณได้ ขณะ Browser View ทำงาน และนานสุด 2 ชั่วโมงหลังจากหยุดอย่างไม่คาดคิด แต่ไม่มีข้อมูลใดเปิดอะไรได้หากไม่อยู่บนฮอตสปอตหรือ Wi‑Fi ของโทรศัพท์คุณ ข้อมูลจะถูกลบ 30 วันหลังจาก Browser View ทำงานครั้งล่าสุด ชื่อ `commaview.app` ของโทรศัพท์และวันที่ของใบรับรองล่าสุดจะอยู่ตราบที่บัญชีของคุณยังอยู่ และชื่อนั้นอยู่ในบันทึกใบรับรองสาธารณะ [นโยบายความเป็นส่วนตัว](/privacy) มีรายละเอียด

## การขับขี่ของคุณในโทรศัพท์

- **เก็บช่วงเวลานี้** ปุ่ม **เก็บ** ของ Live View เก็บ 3 นาทีที่ผ่านมาและอีกหนึ่งนาทีถัดไปของการขับ แตะอีกครั้งภายในนาทีนั้นจะเพิ่มอีกหนึ่งนาที สูงสุด 10 นาที ไม่มีการดาวน์โหลดระหว่างขับ: เมื่อจอดรถ จะคัดลอกเป็น MP4 ในโทรศัพท์
- **ส่งออกทั้งการขับขี่…** ในเมนูเพิ่มเติมของการขับขี่: กล้องหน้าเป็น MP4 ไฟล์เดียว แบ่งเป็นส่วนเมื่อเกิน 3.5 GB ชีตจะบอกขนาดและบอกว่าพื้นที่พอหรือไม่ก่อนดาวน์โหลดอะไร
- **ดึงการขับขี่อัตโนมัติ** การตั้งค่า › การบันทึก: การขับขี่ใหม่จะถูกคัดลอกเมื่ออยู่บ้านประมาณทุกครึ่งชั่วโมง บนเครือข่าย Wi‑Fi ที่คุณเลือก ผ่าน Wi‑Fi เท่านั้น จนถึงพื้นที่ที่คุณให้ไว้ การขับหนึ่งชั่วโมงประมาณ 4.5 GB
- **ไฟดับ?** การบันทึกจะเตือนเมื่อ comma ไฟดับตอนการขับจบ และบอกวิธีแก้

ทั้งหมดนี้เป็นภาพกล้องหน้าโดยไม่มี HUD และอยู่ในโทรศัพท์ต่อไปแม้ comma จะลบการขับขี่นั้นทิ้งแล้ว

## แพ็กโอเวอร์เลย์

การตั้งค่า › **แพ็กโอเวอร์เลย์** หรือการ์ดบนหน้าแรก จะเปิดร้าน แพ็กเพิ่มสิ่งที่ฟอร์กของคุณวาดบนหน้าจอของตัวเองเข้าไปใน Live View เช่น มาตรวัดไฮบริดของ BluePilot หรือเส้นทางสีรุ้งของ dragonpilot สมาชิกเลือกดูแพ็ก **ทางการ** ของ CommaView แพ็กของ **ชุมชน** และ **สำหรับ comma ของคุณ** แต่ละแพ็กมีตัวอย่างสำหรับดีไซน์ที่ Live View วาด **แพ็กของคุณ** มีสวิตช์เดียวสำหรับโทรศัพท์และ comma ทุกเครื่องที่จับคู่ไว้ ถ้าไม่ได้เป็นสมาชิก คุณเพิ่มแพ็กจากไฟล์หรือลิงก์ได้

## มีอะไรอีกใน 0.0.166

- **การนำทางด้วยคีย์ Stadia Maps ของคุณเอง** สำหรับสมาชิก: การตั้งค่า › แผนที่และการนำทาง › คีย์ Stadia Maps ของคุณ
- **BluePilot, dragonpilot และ OPGM** เป็นฟอร์กที่อยู่ในรายการแล้ว เมื่อใช้รันไทม์ใหม่ ยังไม่มีตัวไหนได้ขับกับ CommaView
- **Live View บนจอในรถมากขึ้น**: เมื่อตัวถอดรหัสวิดีโอของโทรศัพท์เล่นวิดีโอของ comma ไม่ได้ จะลองตัวอื่น
- **เปิด CommaView เอง** เมื่อจอในรถเริ่มทำงานหรือ Bluetooth เชื่อมต่อ และ **เปิด Live View เมื่อเชื่อมต่อ** ในการตั้งค่า › การแสดงผล ใช้ CommaView บนหน้าจอของรถเอง: [Android AI box ที่ดีที่สุด](/th/blog/android-ai-box-commaview)
- **แชร์กับผู้พัฒนาฟอร์กของฉัน**: คลิป สรุป และล็อกของ CommaView ให้คุณแชร์เอง
- **Live View บอกว่าเกิดอะไรขึ้น**: การรีบูตที่รออยู่ ข้อมูลรถที่หยุดส่ง ภาพที่ล่าช้า สาเหตุที่กำลังเชื่อมต่อใหม่ และอุปกรณ์อื่นที่เปิดอยู่
- **การอัปเดต CommaView** สำหรับสมาชิก ตั้งแต่ 0.0.166: แสดงเวอร์ชันก่อน มี **ยกเลิกการดาวน์โหลด** และการดาวน์โหลดทำต่อในเบื้องหลัง
- **ขอบจอ** ปลายทางถ่ายทอดสดแยกตามแพลตฟอร์ม และไม่มีอะไรถูกตัดเมื่อใช้ข้อความขนาดใหญ่
