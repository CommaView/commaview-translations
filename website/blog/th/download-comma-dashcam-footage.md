อยากดึงวิดีโอออกจากอุปกรณ์ comma? ทางที่ใช้กันมีสามทาง: comma connect, Openpilot Toolkit หรือเข้าถึงตรงผ่าน SSH/SFTP

ส่วนที่ทำให้คนสับสนคือโครงสร้างไฟล์ อุปกรณ์ comma บันทึกเส้นทางของ openpilot เป็นเซกเมนต์สั้นๆ ไม่ใช่คลิปกล้องติดรถยาวคลิปเดียว แต่ละเซกเมนต์อาจมีไฟล์กล้องดิบ วิดีโอตัวอย่าง และล็อกของเส้นทาง เมื่อเข้าใจตรงนี้ การส่งออกวิดีโอก็ไม่ลึกลับอีกต่อไป

ข้อสำคัญก่อนเริ่ม: อุปกรณ์ comma มีประโยชน์สำหรับวิดีโอถนน การดีบัก และการทบทวนเส้นทาง แต่ไม่ใช่สิ่งที่ใช้แทนกล้องติดรถโดยเฉพาะได้ทันที

## อุปกรณ์ comma เป็นกล้องที่มีประโยชน์ ไม่ใช่กล้องติดรถที่สมบูรณ์แบบ

กล้องติดรถโดยเฉพาะสร้างมาเพื่อเก็บหลักฐาน: บูตเร็ว ทนต่อการชน มีโหมดจอด ส่งออกไฟล์ง่าย มีตัวเลือกกล้องหลัง และมีที่เก็บข้อมูลแบบถอดได้

อุปกรณ์ comma สร้างมาเพื่อรัน openpilot มันบันทึกข้อมูลเส้นทางเพราะมีประโยชน์ต่อโมเดลการขับ การดีบัก ตัวอย่างใน connect และการพัฒนา วิดีโอนั้นมีค่า แต่ก็มีข้อแลกเปลี่ยน:

- การดึงวิดีโออาจยากกว่าการถอดการ์ด SD
- การชนหรือไฟดับกะทันหันอาจทำให้วิดีโอล่าสุดหายไป
- การบันทึกขณะจอดไม่ใช่เป้าหมายหลักของการออกแบบ
- ไม่มีกล้องติดรถด้านหลัง
- ข้อมูลเก่าในเครื่องจะถูกลบเมื่ออุปกรณ์ต้องการพื้นที่

ถ้าเป้าหมายคือวิดีโอการชนที่พึ่งพาได้ ให้ใช้กล้องติดรถจริง ถ้าเป้าหมายคือวิดีโอเส้นทางของ openpilot การทบทวนเพื่อพัฒนา หรือการส่งออกวิดีโอภายในเครือข่าย วิธีทำงานของ comma ก็คุ้มที่จะเรียนรู้

## openpilot บันทึกไฟล์อะไรบ้าง?

เอกสารทางการเรื่องการบันทึกล็อกของ openpilot อธิบายว่าเส้นทางแบ่งเป็นเซกเมนต์ละหนึ่งนาที ในแต่ละเซกเมนต์ openpilot รุ่นปัจจุบันบันทึกไฟล์เหล่านี้:

| ไฟล์ | สิ่งที่อยู่ข้างใน |
| --- | --- |
| `fcamera.hevc` | วิดีโอกล้องหน้า H.265/HEVC |
| `ecamera.hevc` | วิดีโอกล้องหน้ามุมกว้าง H.265/HEVC |
| `dcamera.hevc` | วิดีโอกล้องฝั่งคนขับ/ห้องโดยสาร H.265/HEVC |
| `qcamera.ts` | ตัวอย่าง H.264 ความละเอียดต่ำจากกล้องหน้า |
| `rlog.zst` | ล็อกเส้นทางแบบเต็ม |
| `qlog.zst` | ล็อกเส้นทางแบบย่อ/ลดทอน |

วิดีโอที่แสดงใน comma connect คือ `qcamera.ts` ความละเอียดต่ำ วิดีโอกล้องความละเอียดเต็มอยู่ในไฟล์ HEVC และอาจต้องอัปโหลดเองผ่าน connect หรือคัดลอกตรงจากอุปกรณ์

เส้นทางเก่า ฟอร์กเก่า หรือเอกสารเก่าอาจแสดง `rlog`/`qlog` ที่ไม่มี `.zst` หรือชื่อล็อก `.bz2` แบบเก่า สำหรับ openpilot ปัจจุบัน ใช้ชื่อตามด้านบน

## comma 3, comma 3X และ comma four: อะไรต่างกัน?

มีสองเรื่องที่คนมักปนกัน: ฮาร์ดแวร์กล้อง และโครงสร้างไฟล์

ฮาร์ดแวร์กล้องต่างกันตามรุ่น:

| อุปกรณ์ | กล้อง/พื้นที่เก็บข้อมูล |
| --- | --- |
| comma 3 | กล้อง 1080p สามตัว HDR 120 dB เอกสารจากชุมชนระบุพื้นที่เก็บข้อมูลหลายแบบ: 1TB, 250GB, 64GB รุ่นหลัง และ 32GB รุ่นแรก |
| comma 3X | กล้องสามตัวแบบเดียวกับ comma 3 อัปเกรดเซนเซอร์ภาพ OX03C10 HDR 140 dB และมักระบุพื้นที่ 128GB |
| comma four | comma บอกว่ามีพลังประมวลผล ชุดเซนเซอร์ และความสามารถเหมือน comma 3X แต่ตัวเครื่องเล็กลงมาก ระบบกล้องสามตัวอยู่ในพื้นที่ของหน้าจอ 1.9 นิ้ว มีกล้องมองถนนสองตัวและกล้องห้องโดยสารแบบมองกลางคืน comma ระบุพื้นที่ 128GB และวิดีโอ 10 ชั่วโมง |

ข้อมูลเรื่องไฟล์ในที่นี้ใช้กับทั้งสามรุ่น ส่วน CommaView เองใช้ได้กับ comma 3X และ comma four เท่านั้น

สำหรับ openpilot ปัจจุบัน โครงสร้างไฟล์ที่ใช้จริงเหมือนกันทุกฮาร์ดแวร์ของ comma ไฟล์เซกเมนต์รุ่นใหม่คือ `fcamera.hevc`, `ecamera.hevc`, `dcamera.hevc`, `qcamera.ts`, `rlog.zst` และ `qlog.zst`

แปลว่ากล้องเปลี่ยนทางกายภาพได้ แต่ชื่อไฟล์ที่ส่งออกยังคุ้นเคย `fcamera.hevc` คือกล้องหน้า `ecamera.hevc` คือกล้องหน้ามุมกว้าง `dcamera.hevc` คือกล้องฝั่งคนขับ/ห้องโดยสาร

ถ้าคุณใช้ฟอร์ก ตรวจบนอุปกรณ์ก่อนจะคิดว่ามีครบทุกไฟล์ ฟอร์กอาจเปลี่ยนการตั้งค่าการบันทึก และการบันทึกกล้องฝั่งคนขับ/ห้องโดยสารอาจขึ้นกับการตั้งค่าของอุปกรณ์

## ไฟล์เก็บไว้ที่ไหนในเครื่อง?

บนฮาร์ดแวร์ของ comma โฟลเดอร์รากของล็อก openpilot ปัจจุบันคือ:

```text
/data/media/0/realdata
```

ในโฟลเดอร์นั้น แต่ละเซกเมนต์ของเส้นทางมีโฟลเดอร์ของตัวเองที่ตั้งชื่อตามเวลา เช่น:

```text
/data/media/0/realdata/2026-05-14--12-30-05--3/
```

โฟลเดอร์นั้นคือที่ที่คุณจะหาไฟล์อย่าง:

```text
fcamera.hevc
ecamera.hevc
dcamera.hevc
qcamera.ts
rlog.zst
qlog.zst
```

สำหรับการทำงานผ่าน SSH/SFTP โดยตรง นี่คือโฟลเดอร์ที่เริ่มต้น เอกสารทางการอธิบายวิธีเชื่อมต่อ comma 3X หรือ comma four ผ่าน SSH และ openpilot ใช้ `/data/media/0/realdata` เป็นโฟลเดอร์รากของล็อกบนอุปกรณ์

## ทางเลือกที่ 1: ใช้ comma connect

สำหรับการขับขี่ล่าสุด comma connect มักเป็นจุดเริ่มต้นที่ง่ายที่สุด

ใช้ connect เมื่อ:

- เส้นทางยังใหม่
- อุปกรณ์อัปโหลดเส้นทางสำเร็จแล้ว
- วิดีโอตัวอย่างก็เพียงพอ
- คุณอยากใช้เว็บแทน SSH
- คุณต้องการแค่ไม่กี่คลิปหรือไม่กี่ไฟล์

connect ยังเป็นที่ที่ผู้ใช้หลายคนใช้หาหมายเลขเส้นทางและเซกเมนต์ที่ต้องการเป็นอย่างแรก ข้อควรระวังคือระยะเวลาเก็บ: connect อาจเลิกแสดงเส้นทางก่อนที่อุปกรณ์จะลบมัน ถ้า connect ไม่แสดงเส้นทางแล้วแต่ไฟล์ยังอยู่บนอุปกรณ์ SSH/SFTP อาจยังกู้คืนได้

จำไว้ด้วยว่าตัวอย่างใน connect มาจาก `qcamera.ts` ถ้าต้องการวิดีโอกล้องความละเอียดเต็ม ให้แน่ใจว่าอัปโหลดไฟล์วิดีโอเต็มแล้ว หรือดึงไฟล์ HEVC ดิบโดยตรง

## ทางเลือกที่ 2: ใช้ Openpilot Toolkit

Openpilot Toolkit เป็นเครื่องมือจากชุมชนที่ช่วยให้การส่งออกภายในเครือข่ายง่ายขึ้น มีขั้นตอนสำหรับตั้งค่า SSH เรียกดูไฟล์ ดูตัวอย่างวิดีโอการขับขี่ และส่งออกไฟล์ดิบ

ใช้ Openpilot Toolkit เมื่อ:

- คุณอยากได้ GUI
- คุณไม่อยากพิมพ์คำสั่ง SSH เอง
- คุณต้องการตัวช่วยตั้งค่าคีย์
- คุณใช้ Windows หรือ Android
- คุณอยากเรียกดูและส่งออกวิดีโอของเส้นทางได้ตรงขึ้น

สำหรับผู้ใช้หลายคน นี่คือทางสายกลางที่ดีที่สุด: ควบคุมได้มากกว่า connect และยุ่งยากน้อยกว่าการใช้เทอร์มินัลเอง

## ทางเลือกที่ 3: ใช้ SSH หรือ SFTP โดยตรง

SSH/SFTP โดยตรงให้การควบคุมมากที่สุดและมีตัวช่วยน้อยที่สุด

โดยภาพรวม การเข้าถึงผ่าน SSH มักหมายถึง:

1. สร้างหรือใช้บัญชี GitHub ที่มีคีย์ SSH
2. เปิด SSH ในการตั้งค่าของอุปกรณ์ comma
3. ป้อนชื่อผู้ใช้ GitHub บนอุปกรณ์ comma เพื่อให้มันดึงคีย์สาธารณะของคุณ
4. เชื่อมต่อในชื่อผู้ใช้ `comma` ที่พอร์ต `22`

เมื่อเชื่อมต่อแล้ว เรียกดูหรือคัดลอกจาก:

```text
/data/media/0/realdata
```

ใช้การเข้าถึงโดยตรงเมื่อ:

- คุณต้องการไฟล์ดิบ `fcamera.hevc`, `ecamera.hevc` หรือ `dcamera.hevc`
- connect ไม่แสดงไฟล์ที่คุณต้องการ
- คุณอยากเก็บถาวรทั้งเส้นทาง
- คุณคุ้นเคยกับโปรแกรม SFTP อย่าง FileZilla หรือ WinSCP
- คุณคุ้นเคยกับ `ssh`, `scp` หรือ `rsync`

ไฟล์ `.hevc` ดิบมักเล่นใน VLC ได้ ถ้าแอปอื่นต้องการ MP4 ให้ remux ด้วย ffmpeg แทนการเข้ารหัสใหม่เมื่อทำได้

## ควรใช้วิธีไหน?

ใช้ comma connect ถ้าการขับขี่ยังใหม่และการทบทวนเส้นทางแบบปกติก็พอ

ใช้ Openpilot Toolkit ถ้าคุณอยากได้วิธีทำงานภายในเครือข่ายที่ใช้ง่ายกว่า โดยไม่ต้องทำทุกขั้นตอน SSH/SFTP เอง

ใช้ SSH หรือ SFTP ถ้าคุณต้องการไฟล์ดิบ ไฟล์เก่าในเครื่อง การเก็บถาวรทั้งเส้นทาง หรือควบคุมเองโดยตรงว่าจะคัดลอกอะไร

## CommaView อยู่ตรงไหน

CommaView คือแอป Android ที่ทำงานภายในเครือข่ายเป็นหลัก สำหรับสตรีมกล้องของ comma โอเวอร์เลย์ การตั้งค่ารันไทม์ การบันทึก และการเล่นซ้ำ

มันอยู่ในโลกเดียวกันของการเข้าถึงกล้องภายในเครือข่าย แต่ไม่ใช่ comma connect ไม่ใช่ Openpilot Toolkit และไม่ใช่กล้องติดรถแบบดั้งเดิม ไม่ควรใช้เป็นตัวช่วยขับ หรือเป็นระบบเก็บหลักฐานเพียงอย่างเดียวในรถ

CommaView ใช้ได้กับ comma 3X และ comma four ที่ใช้ openpilot หรือ[ฟอร์กที่รองรับ](/th/forks): sunnypilot, StarPilot, xnor, AdventurePilot, SunnyPilot-TeslaHW1 หรือ carrotpilot ไม่รองรับ comma 3: comma ย้ายมันไปอยู่บน openpilot รุ่นระยะยาวที่หยุดพัฒนาแล้ว ซึ่งหน้าจอของรุ่นนั้น CommaView ใช้วาดโอเวอร์เลย์ไม่ได้ ([ทำไม](/th/#faq-comma-3))
