CommaView 0.0.166 已向 Beta 的所有成员推出。配合新的运行环境，**每部手机都会获得一把自己的密钥** 来连接您的 comma，而且谁都不需要重新配对。CommaView 新增 **11 种语言**，通过 **Browser View** 在车辆的网页浏览器中显示 Live View，借助 **保存此片段**、**导出完整行程…** 和 **自动拉取行程** 把您的行程保存在手机上，并开放了 **叠加包商店**。

它配套运行环境 `v0.0.62-beta`。**请先更新 CommaView**，然后在应用提示时从应用中更新运行环境，并在应用要求时重启 comma。仍停留在 0.0.165 的手机，在您 comma 的第一部手机获得密钥后的 90 天内仍可继续使用。请不要从 0.0.165 的手机上重新设置您的 comma：从它进行设置会装回旧的运行环境，而持有密钥的手机将无法通过旧运行环境连接 comma。

## 每部手机一把密钥

配合新的运行环境，每部手机都会获得一把自己的密钥来连接您的 comma，取代以前每部手机都发送的共享令牌。密钥从不经过网络传输，也没有人需要重新配对：0.0.166 的手机会在下一次连接时获得密钥。

- **新手机获得了密钥。** 当另一部手机获得密钥时，每部持有密钥的手机都会收到通知，并提供 **这是我的**、**移除** 和 **查看手机**；后者会打开 设备设置 › 配对其他手机，所有持有密钥的手机都列在那里。
- **添加手机。** 在持有密钥的手机上点按 **显示邀请码**，会得到一个配对码或二维码，10 分钟内有效。
- **旧版应用。** 在第一部手机获得密钥后的 90 天内，或在有人点按 **立即停止** 之前，您的 comma 仍接受旧的共享令牌。在此之前，**用于旧版应用的配对码** 可以配对旧版 CommaView 的手机。之后，没有密钥的手机需要 0.0.166 和一个邀请码。

## 用您的语言使用 CommaView

设置 › **语言** 现在除英语外，还提供 Deutsch、Español、Français、日本語、한국어、Português (Brasil)、ไทย、Türkçe、Українська、简体中文 和 繁體中文。默认的 **跟随手机语言** 会选用您手机语言列表中 CommaView 支持的第一种语言，没有则用英语，这一行会显示当前使用的语言。在 Android 13 及更高版本上，Android 的按应用设置语言功能也可以使用。

除英语外，所有语言都是 **机器翻译**，还没有母语者审阅过任何一种，所以难免会有用词错误和别扭的句子。“设置”顶部的一张卡片会说明这一点，**帮助改进** 会打开 CommaView 的翻译页面，任何人都可以在那里提出更好的译法。您也可以在 [Discord](https://discord.gg/UuMhz9K8ft) 上或通过 **反馈问题或提出建议** 告诉我们：请说明是哪个界面，以及它现在显示的是什么。

- **comma 的画面保持 comma 的语言。** 分支版本的标签和 comma 的警告会按车上显示的样子绘制；当您的 comma 设为中文、日语、韩语或泰语时，现在会使用分支版本自己的字体。
- **以英文版本为准** 的是排行榜的同意条款，**显示英文版** 可以查看英文原文。隐私政策和条款为英文。
- **日期** 按您所用语言的顺序显示；直播的 YouTube 标题和说明在您修改之前，使用应用的语言。
- **韩语** 在行尾会保持词语完整。在 Android 13 及更早版本上，您为 comma 或地点起的韩语名称仍可能被断开。

## Browser View

Browser View 会在车辆的网页浏览器中显示 Live View 的画面，由您的手机通过它的热点或 Wi‑Fi 提供。从 Live View › 详细信息 › Browser View 启动，在车辆的浏览器中输入短链接 `commaview.app/<code>`，然后点按 **打开**。在 Tesla 上，请先点按 **开启 VPN 地址**。

画面从您的手机直接传到车上，绝不经过互联网；只有短链接的页面经过互联网。登录后，您的手机会获得一个专属名称和一份受信任的证书，因此 Tesla 会显示锁形图标，并使用更流畅的 H.264 画面。未登录时，Tesla 使用基本画质。

- **车内控件**：录制、保存、地图、行车画面、直播和车内摄像头，位于画面旁边或下方，绝不会盖住画面。
- **车上没有网络？** **显示地址** 会列出手机自己的地址。
- 720p 或 1080p、八位数代码，以及 **随 Live View 开始**：每次打开 Live View 时自动启动。

完整步骤（包括 Tesla 的）：[Browser View](/zh-cn/guides/browser-view)。

运行期间，您的手机会把代码、端口和私有地址发送给 CommaView 的账号服务，以便短链接找到它。在 Browser View 运行期间，以及它意外停止后最多 2 小时内，任何拿到代码的人都能看到这些信息和您手机的 `commaview.app` 名称，但没有您手机的热点或 Wi‑Fi，这些信息打不开任何东西。它们会在 Browser View 最后一次运行 30 天后删除。您手机的 `commaview.app` 名称及其最后一份证书的日期会随您的账号一直保留，并且该名称会出现在公开的证书日志中。详情请见[隐私政策](/privacy)（英文）。

## 把行程保存在手机上

- **保存此片段。** Live View 的 **保存** 会保留行程中此前的 3 分钟和接下来的 1 分钟；在这一分钟内再点按一次会多加一分钟，最长 10 分钟。行驶中不会下载任何内容：停车后，它会被复制成手机上的一个 MP4。
- **导出完整行程…** 在行程的 **更多** 菜单中：把道路摄像头画面导出为一个 MP4，超过 3.5 GB 时分成多个部分。在下载任何内容之前，面板会显示它有多大、是否放得下。
- **自动拉取行程。** 设置 › 录像：在您选择的 Wi‑Fi 网络上，新行程大约每半小时复制回家一次，只通过 Wi‑Fi，最多占用您给它的空间。一小时的行程约为 4.5 GB。
- **断电了？** 当行程结束时 comma 断电，“录像”会发出警告，并说明如何解决。

以上内容都是不带 HUD 的道路摄像头画面，即使 comma 轮换删除了这段行程，也会保留在您的手机上。

## 叠加包

设置 › **叠加包** 或首页上的卡片会打开商店。叠加包会把分支版本在自己屏幕上绘制的内容加到 Live View 中，例如 BluePilot 的混合动力仪表或 dragonpilot 的彩虹路径。会员可以浏览 CommaView 的 **官方** 叠加包、**社区** 的叠加包以及 **适用您的 comma** 的叠加包，每个都附有 Live View 所绘制样式的预览。**您的叠加包** 用一个开关同时控制您的手机和所有已配对的 comma。没有会员资格时，您可以从文件或链接添加叠加包。

## 0.0.166 的其他改进

- **使用您自己的 Stadia Maps 密钥进行导航**，面向会员：设置 › 地图与导航 › **您的 Stadia Maps 密钥**。
- **BluePilot、dragonpilot 和 OPGM** 成为列出的分支版本，需要新的运行环境。它们都还没有搭配 CommaView 实际驾驶过。
- **Live View 支持更多车机**：当手机的视频解码器无法播放 comma 的视频时，它会尝试另一个解码器。
- 在车机启动或蓝牙连接时 **自动打开 CommaView**，以及 **连接时打开 Live View**，都在 设置 › 显示 中。想在车辆自己的屏幕上运行 CommaView：[最适合的 Android AI 盒子](/zh-cn/blog/android-ai-box-commaview)。
- **分享给我的分支版本开发者…**：一段短片、一份摘要和 CommaView 的日志，由您自己分享。
- **Live View 会说明发生了什么**：它在等待的重启、中断的车辆数据、延迟的画面、重新连接的原因、另一台已打开它的设备。
- **更新 CommaView**，面向会员，从 0.0.166 起：先显示版本，可以 **取消下载**，下载会在后台继续。
- **屏幕边缘**、为每个平台分别设置的直播目的地，以及大字号下不再有内容被截断。

## 如何更新

CommaView 目前处于仅限邀请的 Beta 阶段。如果您已加入，应用会自动提供 0.0.166。先更新 CommaView，再在应用中更新 comma 的运行环境，并在提示时重启 comma。请在第一部手机获得密钥后的 90 天内，更新所有观看您 comma 的手机和车机。
