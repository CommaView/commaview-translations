CommaView 0.0.166 を Beta の全員に公開しました。新しいランタイムでは、**スマートフォンごとに comma 用の専用の鍵** が発行され、ペアリングし直す必要はありません。CommaView は **11 の言語** に新たに対応し、**Browser View** で車の Web ブラウザーに Live View を表示し、**この場面を保存**、**ドライブ全体を書き出し…**、**ドライブを自動で取得** でドライブをスマートフォンに残し、**オーバーレイパックストア** を開きます。

ランタイム `v0.0.62-beta` が同梱されています。**先に CommaView をアップデートし**、アプリが案内したらアプリからランタイムをアップデートし、求められたら comma を再起動してください。0.0.165 のままのスマートフォンは、comma で最初のスマートフォンが鍵を受け取ってから 90 日間は動き続けます。0.0.165 のスマートフォンから comma をセットアップし直さないでください。そのスマートフォンからのセットアップは古いランタイムに戻してしまい、鍵を持つスマートフォンはそのランタイムの comma に接続できません。

## スマートフォンごとの鍵

新しいランタイムでは、これまですべてのスマートフォンが送っていた共有トークンに代わり、スマートフォンごとに comma 用の専用の鍵が発行されます。鍵がネットワークを通ることはなく、ペアリングし直す必要もありません。0.0.166 のスマートフォンは、次に接続したときに鍵を受け取ります。

- **新しいスマートフォンが鍵を受け取ったとき。** 鍵を持つ各スマートフォンに、別のスマートフォンが鍵を受け取ったことが通知されます。通知には **自分のものです**、**削除**、**スマートフォンを確認** があり、「スマートフォンを確認」は デバイス設定 › 別のスマートフォンをペアリング を開きます。ここに鍵を持つすべてのスマートフォンが並びます。
- **スマートフォンの追加。** 鍵を持つスマートフォンで **招待を表示** をタップすると、10 分間有効なコードか QR コードが表示されます。
- **古いアプリ。** comma は、最初のスマートフォンが鍵を受け取ってから 90 日間、または誰かが **今すぐ停止** をタップするまで、古い共有トークンを受け付けます。それまでは、**古いアプリ用のペアリングコード** で古い CommaView のスマートフォンをペアリングできます。それ以降、鍵のないスマートフォンには 0.0.166 と招待が必要です。

## あなたの言語で CommaView を

設定 › **言語** で、英語に加えて Deutsch、Español、Français、日本語、한국어、Português (Brasil)、ไทย、Türkçe、Українська、简体中文、繁體中文 を選べるようになりました。デフォルトの **スマートフォンの言語** は、スマートフォンの言語リストのうち CommaView が対応している最初の言語を使い、なければ英語を使います。どの言語を使っているかは、その行に表示されます。Android 13 以降では、Android のアプリごとの言語設定も使えます。

英語以外の言語はすべて **機械翻訳** で、まだネイティブスピーカーのレビューを受けていません。おかしな言葉やぎこちない文があるはずです。設定の一番上のカードでもそのことをお知らせしており、**改善に協力する** をタップすると CommaView の翻訳ページが開き、誰でもより良い言葉を提案できます。[Discord](https://discord.gg/UuMhz9K8ft) や、「問題を報告、またはアイデアを送る」から伝えていただくこともできます。画面の名前と、今の表示内容を教えてください。

- **comma の画面は comma の言語のままです。** フォークのラベルや comma のアラートは車に表示されるとおりに描かれます。comma が中国語、日本語、韓国語、タイ語のときは、フォーク自身のフォントで描くようになりました。
- **ランキングの同意には英語の文章が適用されます。** **英語で表示** で英語の文章を表示できます。プライバシーポリシーと利用規約は英語です。
- **日付** は言語の順序に従います。ライブ配信の YouTube のタイトルと説明も、変更するまではアプリの言語になります。
- **韓国語** では、行末で単語を分割しません。Android 13 以前では、comma や場所に付けた韓国語の名前が途中で改行されることがあります。

## Browser View

Browser View は、Live View が表示しているものを車の Web ブラウザーに表示します。映像はスマートフォンがテザリングまたは Wi‑Fi 経由で配信します。Live View › 詳細 › Browser View から開始し、車のブラウザーに短いリンク `commaview.app/<code>` を入力して **開く** をタップします。Tesla では、先に **VPN アドレスをオン** にしてください。

映像はスマートフォンから車へ直接届き、インターネットを通りません。インターネットを通るのは短いリンクのページだけです。ログインしていると、スマートフォンに専用の名前と信頼された証明書が付くので、Tesla では鍵マークが表示され、より滑らかな H.264 の映像になります。ログインしていない場合、Tesla では Basic の映像になります。

- **車内での操作**：録画、保存、地図、走行画面、配信を開始、ドライバーカメラ。映像の横か下に表示され、映像に重なることはありません。
- **車内にインターネットがない場合**は、「アドレスを表示」でスマートフォン自身のアドレスが一覧表示されます。
- 720p または 1080p、8 桁のコード、そして Live View を開くたびに自動で始める **Live View と一緒に開始**。

Tesla の場合も含めた全手順は [Browser View](/ja/guides/browser-view) をご覧ください。

Browser View の動作中、短いリンクがスマートフォンを見つけられるよう、スマートフォンは CommaView のアカウントサービスにコード、ポート、プライベートアドレスを送ります。コードを知っている人は、Browser View の動作中と、予期せず停止してから最大 2 時間、それらとスマートフォンの `commaview.app` の名前を見ることができます。ただし、スマートフォンのテザリングや Wi‑Fi なしでは、どれを使っても何も開けません。これらは Browser View を最後に使ってから 30 日後に削除されます。スマートフォンの `commaview.app` の名前と最新の証明書の日付はアカウントがある限り残り、名前は公開の証明書ログに載ります。詳しくは[プライバシーポリシー](/privacy)（英語）をご覧ください。

## ドライブをスマートフォンに

- **この場面を保存。** Live View の **保存** は、ドライブの直前 3 分と、その後の 1 分を残します。その 1 分の間にもう一度タップすると 1 分延び、最大 10 分までです。運転中は何もダウンロードしません。駐車すると、スマートフォンに MP4 としてコピーされます。
- **ドライブ全体を書き出し…** ドライブの「その他」メニューから、道路カメラの映像を 1 つの MP4 として書き出します。3.5 GB を超える場合は分割します。ダウンロードを始める前に、シートにサイズと空き容量に収まるかどうかが表示されます。
- **ドライブを自動で取得。** 設定 › 録画 で設定します。新しいドライブが、選んだ Wi‑Fi ネットワーク上で約 30 分ごとに、Wi‑Fi のみで、割り当てた容量まで手元にコピーされます。1 時間の運転で約 4.5 GB です。
- **電源が落ちた場合。** ドライブの終わりに comma の電源が落ちると、録画で警告が表示され、直し方が案内されます。

どれも HUD のない道路カメラの映像で、comma がそのドライブを入れ替えて消したあともスマートフォンに残ります。

## オーバーレイパック

設定 › **オーバーレイパック**、またはホームのカードからストアが開きます。パックは、フォークが自分の画面に描くものを Live View に加えます。たとえば BluePilot のハイブリッドゲージや dragonpilot の虹色の走行経路です。メンバーは CommaView の **公式** パック、**コミュニティ** のパック、**あなたの comma 向け** を閲覧でき、それぞれ Live View が描くデザインごとのプレビューが付いています。**あなたのパック** には、スマートフォンとペアリングしたすべての comma に共通のスイッチが 1 つあります。メンバーシップがなくても、ファイルやリンクからパックを追加できます。

## 0.0.166 のその他の変更

- **自分の Stadia Maps キーでナビ**（メンバー向け）：設定 › 地図とナビ › 自分の Stadia Maps キー。
- **BluePilot、dragonpilot、OPGM** が、新しいランタイムで一覧のフォークになりました。どれも CommaView を使った実車走行はまだ行っていません。
- **より多くのカーナビで Live View**：スマートフォンの映像デコーダーが comma の映像を再生できない場合、別のデコーダーを試します。
- カーナビの起動時や Bluetooth の接続時に **CommaView を自動で開く** 設定と、**接続したら Live View を開く** を 設定 › 表示 に追加しました。車の画面で CommaView を動かすには：[CommaView におすすめの Android AI ボックス](/ja/blog/android-ai-box-commaview)。
- **フォークの開発者と共有…**：クリップ、概要、CommaView のログをまとめ、自分で共有できます。
- **Live View が状況を伝える**：待っている再起動、止まった車両データ、遅延している映像、再接続している理由、Live View を開いている別のデバイス。
- **CommaView のアップデート**（メンバー向け、0.0.166 以降）：先にバージョンを表示し、「ダウンロードをキャンセル」でき、ダウンロードはバックグラウンドで続きます。
- **画面の端**、プラットフォームごとのライブ配信の配信先、そして大きな文字でも切れない表示。

## 早期アクセス

X、Twitch、Kick、Facebook へのライブ配信、FrogPilot と KisaPilot 向けの「映像のみ」、フォーク設定、オーバーレイパックの作成、Surround は、引き続き機能フラグを使って限られたテスターだけに公開しています。テストに協力したい方は、[Discord](https://discord.gg/UuMhz9K8ft) でご連絡ください。実際のドライブでどう動いたかを教えていただけると助かります。

## アップデートの方法

CommaView は招待制の Beta です。参加している方には、アプリが 0.0.166 を自動で案内します。CommaView をアップデートし、次にアプリから comma のランタイムをアップデートし、求められたら comma を再起動してください。comma を見ているすべてのスマートフォンとカーナビを、最初の 1 台が鍵を受け取ってから 90 日以内にアップデートしてください。
